# To-Do List

Небольшое веб-приложение для просмотра списка задач с поиском, фильтрацией и просмотром деталей.

## Как запустить проект
1. Скачать или клонировать проект  
2. Открыть файл `index.html` в браузере

## Используемые технологии
HTML  
CSS  
JavaScript  
Fetch API  
JSONPlaceholder API  

## Функциональность
- загрузка задач с сервера  
- отображение списка задач  
- поиск по названию  
- фильтр по статусу  
- модальное окно с деталями задачи  
- загрузка информации о пользователе (имя и email)
